Diwali Lights

Shine colorful lights in your browser — a small Diwali treat for developers.

  1. Enter Box Count — type how many boxes you want in the box count field.
  2. Click Submit — this creates the boxes in the grid (skeleton shows briefly).
  3. Adjust Timer — use the slider to set seconds between color changes; changing while running updates speed immediately.
  4. Play / Pause — click the play icon to start the lights; the same button pauses.

Hover a step to highlight the relevant control. Click a step to focus it.
